## 아직 공개하지 않은 것: Windows 포터블 실행본
개발 PC에서 만든 포터블 ZIP(Python 런타임과 모든 의존성 동봉)은 Windows 10/11 x64에서 실행·실변환 시험을 통과했지만, **공개 재배포 준비가 끝나지 않아 올리지 않았습니다.** 확인된 항목:

1. **Microsoft Visual C++ 런타임 DLL**: 재배포 권한이 Visual Studio 사용권 조건에 묶여 있습니다. PyPI 패키지에서 꺼낸 DLL이나 서명만으로는 재배포 권한이 확인되지 않습니다. scikit-learn·llvmlite 휠 안에도 별도 사본이 있습니다.
2. **libsndfile 1.2.2 (soundfile 휠 동봉, LGPL-2.1)**: Windows DLL에 LAME 3.100, mpg123 등 LGPL 코덱이 정적으로 포함되어 있습니다. 빌드에 쓰인 vcpkg 기준점이 고정되어 있지 않아 정확한 대응 소스·패치 세트가 아직 확정되지 않았습니다.
3. **soxr 1.1.0 (LGPL-2.1-or-later)**: libsoxr 포크(dofuuz/soxr a66f3ee)가 정적으로 포함되어 있어 래퍼와 포크의 전체 소스·빌드 파일이 필요합니다.
4. **NumPy 1.26.4 OpenBLAS DLL 안의 libquadmath (LGPL-2.1-or-later)**: 정적 포함되어 있어 대응 소스와 재링크 가능 자료가 필요합니다.
5. Python 3.11.9 공식 embed 런타임은 3.11 계열의 최신 보안 패치판이 아닙니다.
